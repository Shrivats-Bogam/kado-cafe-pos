## 2. Standardized Incident Model & Alert Deduplication

Created [`src/lib/incidentEngine.js`](file:///C:/Users/Admin/.gemini/antigravity/worktrees/kado-cafe/redesign_tables_pos_ui/src/lib/incidentEngine.js) and database schema [`supabase/b16_incidents_schema.sql`](file:///C:/Users/Admin/.gemini/antigravity/worktrees/kado-cafe/redesign_tables_pos_ui/supabase/b16_incidents_schema.sql):
- **Incident Event Schema**: `incidentId`, `correlationId`, `organizationId`, `severity` (`P0`, `P1`, `P2`, `P3`), `category`, `eventType`, `status` (`DETECTED`, `INVESTIGATING`, `MITIGATED`, `RESOLVED`, `CLOSED`), `fingerprint`, `safeMetadata`.
- **Alert Deduplication**: `generateFingerprint(orgId, eventType, resourceId)` groups repeated failures within a 5-minute bucket into a single incident record with an incrementing duplicate count.
- **System Health Evaluator**: Computes aggregate health status: `HEALTHY`, `DEGRADED`, `CRITICAL`, or `OFFLINE`.
