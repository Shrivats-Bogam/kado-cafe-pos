## 2. Identified Gaps & Operational Risks

1. **Automated Secret Scanning**: Prior to B1.5, secret checks were manual. An automated scanner is required in CI to scan `src/` and `dist/` before deployment.
2. **Classified npm Test Scripts**: `package.json` lacked explicit targets e.g. `test:unit`, `test:security`, `test:integration`, `test:e2e`, `test:smoke`, `test:rc`.
3. **Machine-Readable Release Gates**: No automated JSON release gate artifact (`docs/release-gate-result.json`) was exported prior to release deployment.
4. **Production Smoke Testing**: Need a dedicated read-only production smoke test suite (`b15ProductionSmoke.js`) that verifies live UI routing without performing financial mutations in production.
