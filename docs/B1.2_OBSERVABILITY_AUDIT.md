## 1. Application Error & Security Event Monitoring Architecture

Created [`src/lib/observability.js`](file:///C:/Users/Admin/.gemini/antigravity/worktrees/kado-cafe/redesign_tables_pos_ui/src/lib/observability.js) and database schema [`supabase/b12_observability_schema.sql`](file:///C:/Users/Admin/.gemini/antigravity/worktrees/kado-cafe/redesign_tables_pos_ui/supabase/b12_observability_schema.sql):
- **Request Correlation IDs**: Generated via `createCorrelationId(prefix)` (e.g., `corr_pay_1786637731035_4a1opqf`), allowing end-to-end reconstruction of payment, refund, inventory, order, and backup lifecycles.
- **Log Privacy & Sanitization**: `sanitizeLogData()` automatically redacts PINs, passwords, secrets, service-role keys, JWT tokens, payment credentials, and customer phone numbers before storing or printing log events.
- **Security Event Categories**: `SECURITY_LOGIN_FAILURE`, `SECURITY_DISABLED_ACCOUNT`, `SECURITY_TENANT_ACCESS_DENIED`, `SECURITY_ROLE_ESCALATION`, `SECURITY_BACKUP_TAMPER`, `SECURITY_UNAUTHORIZED_REFUND`, `SECURITY_UNAUTHORIZED_PAYMENT`.
