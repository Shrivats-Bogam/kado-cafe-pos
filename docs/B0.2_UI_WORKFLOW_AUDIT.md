# Sprint B0.2: Real UI Workflow & Persistence Audit

## Executive Summary
This document records the comprehensive E2E audit of the **Kado Cafe POS** application. Sprint B0.2 replaced synthetic unit tests with actual browser automation via **Puppeteer**, testing complete end-to-end user interactions (click, type, navigate, reload) across all 10 POS modules.

All interactive elements were instrumented with stable `data-testid` attributes without changing application behavior. Isolated test data tagged with `E2E_B02_` was used to verify UI workflows, state mutations, persistence across browser reloads, and financial/inventory invariants.

## Discovered Bugs & Remediation Ledger

| Bug ID | Module | Issue Description | Root Cause | Fix Applied | Status |
|--------|--------|-------------------|------------|-------------|--------|
| **BUG-B02-001** | Tables | Uncaught `TypeError` when clicking "Next Step" in Add Table Wizard | Default tables lacked a `.name` property (`t.name` was `undefined`), causing `t.name.toLowerCase()` to throw | Updated `TableModal.jsx` to safely fallback: `(t.name \|\| \`Table ${t.number}\`).toLowerCase()` | **FIXED & VERIFIED** |
| **BUG-B02-002** | Recipes / UI | Recipe ingredient quantity forced to `0.001` when typing decimal numbers | Controlled `<input value={row.qty} />` converted `"0"` to `0.001` on first keystroke mid-typing | Refactored `RecipeBuilder.jsx` to maintain raw input value during edit and sanitize to number on save | **FIXED & VERIFIED** |
